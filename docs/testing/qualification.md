## Material limits to resolve or retain explicitly

- Copilot execution is live-qualified. The Codex adapter and sign-in flow are implemented, with real protocol and simulated lifecycle checks; live Codex/mixed-provider execution awaits an explicit account sign-in. Missing configured models wait with retry backoff; ADC does not silently substitute another model or family.
- Recovery opens a new provider activation from persisted assignment/run/document/review context. It does not yet resume the native provider conversation. Agents are instructed to reconcile external actions before repeating them; exactly-once external effects are not guaranteed.
- Tool calls now retain correlated arguments, results, completion/failure/interruption state, and provider-session identifiers. The UI displays the most recent 100 tool calls and paginates ordinary activity. Displayed payloads are bounded and redacted for configured secrets and recognizable credential forms; redaction cannot identify every possible secret. Assistant text appears at completed-message boundaries, not token by token. Provider usage events are collected and displayed in the Usage view; missing events/counts remain possible and token counts do not establish billing or quota.
- Code checks cover repositories registered with `adc_code`. Agents must commit within their isolated workspace, register each code deliverable, and run repository-specific gates. A broad shell can omit registration or violate publication instructions; initial authority remains advisory.
- A review is attached to a result/document digest and registered code commits. ADC does not independently know every repository's quality gates; agents must discover and execute them. Final remote PR checks still need qualification in the website acceptance.
- The user's actual TrueNAS MCP connection and bounded read-only inventory are qualified through a GPT storage worker and Claude reviewer. This does not qualify write actions, every MCP endpoint, disaster recovery or unavailable SMART/boot-pool/configuration details.
- Conflicting human intent is currently interpreted by the supervisor from shared history and explicit instructions; there is no general deterministic semantic conflict detector.
- Organization membership, member visibility, password login, self-service password changes, other-session revocation, and personal connection editing are present. Rich invitations, forgotten-password recovery, account deletion, and broader production operational hardening are not complete.
- Pending model turns receive human steering on their next activation. This does not interrupt a tool already in progress.
- Three unsuccessful review rounds return responsibility to the supervisor. Three recovery reassignments require a human decision before another recovery cycle. Unrelated work remains eligible to run. These defaults still need tuning against real assignments.
